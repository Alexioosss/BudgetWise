# Budget Wise
A Kotlin-built android app for managing transactions and their recurrences, managing money in and out, and viewing upcoming transactions. App has been built using vibrant colours and accessiblity considerations, such as adjustable font size and theme mode.

# ✨ Features
- Transaction Management - Add, edit, delete categorized transactions, incoming and expense, easily
- Recurring Payments - Automatically track subscriptions, bills, salaries, and repeating transactions
- Cash Flow Overview - See money moving in and out
- Upcoming Transactions - Never miss a transaction
- Vibrant UI - Colorful, modern interface designed for clarity
- Accessibility First - Adjustable font sizes and light/dark themes

# 🛠 Tech Stack
- Kotlin
- Jetpack Compose
- Room Database
- Material 3
